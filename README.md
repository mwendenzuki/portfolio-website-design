## 📝 Project Description

This project is a pixel-perfect recreation of a portfolio website using **HTML**, **CSS**, and **JavaScript**, based on a given reference design (screenshot samples). The website includes the following sections:

- **Header/Navbar**
- **Hero Section**
- **About Section**
- **My Work/Portfolio Section** (with image hover effect)
- **Footer**
- **"Scroll to Top" Button**

The objective of this assignment was to practice layout structuring, styling precision, responsiveness, and interactivity using the core front-end technologies covered during the week.

---

## 💡 Solution Approach

- **HTML5** was used to structure all sections semantically.
- **CSS3** was used to replicate the visual design, including fonts, colors, spacing, and layout.
- **Font Awesome** was used to replace emoji icons with scalable vector icons for a professional look.
- **JavaScript** was implemented for the "scroll to top" functionality.
- The layout is **fully responsive**, adapting to different screen sizes including mobile.
- **Clean and modular code** organization was followed using external `.css` and `.js` files.
- Bootstrap (optional) was referenced but not heavily relied on, to ensure CSS learning was maximized.
